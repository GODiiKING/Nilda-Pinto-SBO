## Nilda Pinto SBO
[Nilda Pinto SBO](https://www.facebook.com/NildaPintoSBOSteenrijk/) is a public secondary vocational school in Curaçao. This website was built as a creative project to showcase professional design and layout skills using only HTML and CSS.

![image](https://github.com/GODiiKING/Nilda-Pinto-SBO/assets/80182745/00e2d8cc-84e8-4220-b8e3-4974f5064148)

Had to [build a Nilda Pinto SBO website](https://nildapinto-sbo.weebly.com/) using the school assignment assets only. Only using HTML and CSS. This is my first-ever project. In which we have 100% creativity in design and code.
